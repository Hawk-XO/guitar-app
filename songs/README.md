# Songs

Songs in this folder show up in the app's **Songs** list for everyone who opens the site.

1. In the app, add a song with **+ Add song** (MusicXML, MIDI or text tab).
2. Click **Save file** — it downloads `<song-name>.json`.
3. Put that file in this folder and add its name to `index.json`, e.g. `["ano-bando.json"]`.
4. Commit and push.

Note: this repo and site are public — anything here can be seen by anyone with the link.
